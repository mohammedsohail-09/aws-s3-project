##DESCRIPTION:

1.Create A S3 Bucket:

Login into your AWS account console and navigate to search bar 

Search for S3 Service

Now click on "Create Bucket"

Enter a unique name for creating a bucket (e.g., "my-cloudbucket1) it should be lower case only.

Now Ensure "Block all public access" is unchecked if you need public access to files

Enable Access Control List(ACL's) for ownerships (It is only for practice purpose only)

Click "Create bucket"

2.Upload Example Files:

Navigate to your newly created bucket

Click on "Upload" button and select a few example files from your local machine (e.g., a text file,an image,a PDF)
 
3.Set Access Permissions:

Now go to permissions and allow  Public Read Access 

And click on Checked box for granting the risk
